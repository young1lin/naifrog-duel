奶蛙 · 私人联机

请输入服务口令。

这台服务器的游戏文件只对已登录的人开放，单机和本地模式也需要先登录。口令不会放进网址、房间消息或浏览器存储。只在服务器主人告诉你的地址输入。

注意：这是未加密的 http:// 连接。口令、登录状态和对局数据以明文经过网络，同一网络上的人可能看到。只在信任的网络使用，这个口令也不要用在别处。

可用字母、数字、空格、_、- 和常用汉字；最多 10 个字母或 6 个汉字。

你的座位由服务器分配：创建者一般是 P1（金色），加入者一般是 P2（蓝色）。画面上标着“你”的那只就是你，“对手”是对方。这台设备上的键盘、手柄、触屏都只控制你自己的角色；触屏左侧摇杆移动（上推跳跃、下拉防御），右侧圆形按钮出招。

重开需双方按 R / 手柄 Start / “再来一局”（或整场结束的结果显示约 1 秒后的手柄 A）确认。等人时房间一直保留（连接靠服务器每 10 秒一次心跳确认）；断线时暂停，席位保留 5 分钟，页面刷新会尝试恢复。服务器权威 60 Hz、快照 20 Hz，画面约 50 ms 插值；没有预测或回滚，延迟取决于服务器位置。

奶蛙对打 · 操作

三个模式在“菜单”里选择：单机打人机、本地同屏双人、私人联机。P1 永远是金色血条与金色标记，P2 永远是蓝色；头顶标签与脚下圆环跟着角色走，“你”是你，“电脑”是电脑，“对手”是联机对手。

P1 键位：A/D 移动，W 跳，S 防御，F 轻拳，G 重拳，H 肚皮冲刺，T 奶泡弹。P2 键位：←/→ 移动，↑ 跳，↓ 防御，J/K/L/I 为轻拳/重拳/冲刺/奶泡弹。单机与联机时两套键位都控制你。

手柄：左摇杆/方向键移动，A 跳，X 轻拳，Y 重拳，B 冲刺，RB（右肩键）奶泡弹，LB / LT / RT 防御，Start 重开（结果显示约 1 秒后 A 也可以），Select（Back / View）暂停并打开菜单、再按一次继续（单机 / 本地）。菜单和房间面板里十字键 / 左摇杆移动，A 或 Start 确认，B 或 Select 返回；联机对局中按 Select 打开房间面板。登录口令仍需键盘输入。浏览器可能要先按一次手柄按钮才能识别。本地双人按连接顺序分配 1 号 / 2 号手柄。

平板建议横屏。触屏设备上会叠加半透明的虚拟摇杆和圆形按钮（电脑上不显示）。左半屏任意位置按下即出现摇杆：左右拖动移动，上推跳跃，下拉防御，拖出圆圈时摇杆跟着手指走。右下角圆形按钮与手柄位置一致：左“轻拳”、上“重拳”、右“冲刺”、下“奶泡”（奶泡弹，自己的奶泡还在场上时变灰）。没有跳跃按钮：摇杆上推跳，斜上推向前 / 向后跳。可以和摇杆同时按住。本地双人：左半屏归 P1、右半屏归 P2，各自一个摇杆和一组按钮。

R / “再来一局”重开（联机需双方确认），F1 显示判定框，Esc 打开菜单。跳起后按轻拳或重拳是肚皮压，每次跳跃一次；按住攻击不会连发。前方防御会被削掉 1/4 伤害。跳起时会缩腿，算准时机能跳过奶泡。奶泡弹和肚皮压的动作暂用占位图。

私人联机可以用 https:// 域名，也可以用没有域名的 http://服务器IP:端口。http:// 不加密：口令和对局数据以明文传输。部分浏览器在 http:// 页面不提供手柄（触屏和键盘不受影响）；“复制匹配码”在 http:// 页面改用兼容方式复制；仍不行时会选中匹配码，长按或按 Ctrl+C 复制。localhost 算安全来源，可调试手柄。
